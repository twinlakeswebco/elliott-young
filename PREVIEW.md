## Preview controls

- The visible `TWIN LAKES / WEB CO.` badge is preview-only. Remove the `preview-watermark` aside and its CSS when the approved site launches.
- Remove `noindex, nofollow` only for the approved production launch.
- Search opens the brokerage's existing Flexmls destination. Email links open the visitor's email app; the office number calls the brokerage. There is no simulated listing feed or contact form.
- The mobile menu supports keyboard interaction and Escape. Navigation remains available with JavaScript disabled.
